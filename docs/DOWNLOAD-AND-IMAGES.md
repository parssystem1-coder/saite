## ۲️⃣ فرمت تصویر مورد نظر شما: **WebP** و **AVIF**

پاسخ کوتاه: فرمتی که توصیف کردید (حجم کم، کیفیت بالا) **WebP** است و نسل جدیدترش **AVIF**.

### مقایسهٔ فرمت‌ها

| فرمت | حجم نسبت به JPEG | کیفیت | پشتیبانی مرورگر | مناسب برای |
|---|:---:|---|:---:|---|
| **JPEG** | مبنا (۱۰۰٪) | خوب | ۱۰۰٪ | — (قدیمی) |
| **PNG** | ۱۵۰–۳۰۰٪ | عالی + شفافیت | ۱۰۰٪ | لوگو، شفافیت |
| **WebP** | **۲۵–۳۵٪ کمتر** | مساوی یا بهتر | ~۹۷٪ | ✅ عکس محصول |
| **AVIF** | **۵۰٪ کمتر** | بهتر | ~۹۳٪ | ✅ بهترین گزینه |
| **SVG** | چند کیلوبایت | بی‌نهایت (برداری) | ۱۰۰٪ | ✅ آیکون و طرح |

### 🎯 خبر خوب: Next.js این کار را **خودکار** انجام می‌دهد

نیازی نیست عکس‌ها را دستی تبدیل کنید. کامپوننت `next/image` این کارها را خودش می‌کند:

1. عکس اصلی (JPG/PNG) را می‌گیرد
2. به‌صورت خودکار به **AVIF یا WebP** تبدیل می‌کند
3. تشخیص می‌دهد مرورگر کاربر کدام را پشتیبانی می‌کند
4. چند اندازهٔ مختلف می‌سازد (موبایل کوچک، دسکتاپ بزرگ)
5. نسخهٔ مناسب همان دستگاه را می‌فرستد

یعنی شما فقط عکس معمولی آپلود می‌کنید و کاربر موبایل، نسخهٔ ۴۰ کیلوبایتی می‌گیرد به‌جای فایل ۸۰۰ کیلوبایتی.

### وضعیت فعلی پروژهٔ شما

```
public/products/  →  ۶ فایل SVG  →  مجموعاً فقط ۲۸ کیلوبایت
```

تصاویر فعلی **SVG برداری** هستند که من در فاز ۱ ساختم:

- ✅ هر کدام حدود **۱.۷ کیلوبایت** (یک عکس JPEG معمولاً ۲۰۰ برابر این است)
- ✅ در هر اندازه‌ای کاملاً واضح‌اند (چون برداری‌اند، نه پیکسلی)
- ✅ بدون نیاز به اینترنت یا سرویس خارجی

**پس تا وقتی از این طرح‌ها استفاده می‌کنید، بهینه‌تر از این ممکن نیست.**

### ⚠️ نکتهٔ مهم برای وقتی عکس واقعی محصولات را اضافه می‌کنید

وقتی عکس واقعی پرینترها را از تأمین‌کننده گرفتید:

```
✅ درست:  عکس اصلی JPG/PNG را در public بگذارید
          → Next.js خودش WebP/AVIF می‌سازد

❌ اشتباه: خودتان دستی WebP بسازید و آن را بدهید
          → Next.js دوباره پردازش می‌کند، بی‌فایده است
```

**توصیهٔ عملی برای عکس محصول:**

| مورد | مقدار پیشنهادی |
|---|---|
| ابعاد اصلی | ۱۲۰۰×۱۲۰۰ پیکسل (مربع) |
| فرمت آپلود | JPG (برای عکس) یا PNG (اگر پس‌زمینه شفاف لازم است) |
| حجم فایل اصلی | زیر ۵۰۰ کیلوبایت |
| پس‌زمینه | یکدست (سفید یا خنثی) |

### 🔧 چیزی که در فاز ۵ اضافه می‌کنم

الان `next.config.ts` پیکربندی تصویر ندارد. در فاز ۵ این را اضافه می‌کنم:

```ts
const nextConfig: NextConfig = {
  images: {
    // ترتیب مهم است: AVIF اول امتحان می‌شود، بعد WebP
    formats: ['image/avif', 'image/webp'],
    deviceSizes: [640, 750, 828, 1080, 1200, 1920],
    imageSizes: [16, 32, 48, 64, 96, 128, 256, 384],
    minimumCacheTTL: 60 * 60 * 24 * 30, // کش ۳۰ روزه
  },
}
```

همچنین **۷ کامپوننت `Image` هنوز ویژگی `sizes` ندارند** — بدون آن، مرورگر
همیشه بزرگ‌ترین نسخه را دانلود می‌کند. این هم در فاز ۵ رفع می‌شود.

## ۳️⃣ دستورات Git Bash برای دانلود در `D:\saite`

### 🅰 حالت اول: اولین بار (پوشه خالی است یا وجود ندارد)

Git Bash را باز کنید و این دستورات را **خط به خط** اجرا کنید:

```bash
# ۱. رفتن به درایو D
cd /d

# ۲. کلون کردن مخزن
git clone https://github.com/parssystem1-coder/saite.git

# ۳. ورود به پوشهٔ پروژه
cd saite

# ۴. 🔑 مهم‌ترین گام: رفتن روی برنچی که تمام فازها آنجاست
git checkout arena/019fbe01-saite

# ۵. تأیید اینکه درست آمده
git log --oneline -5
```

## ۴️⃣ اجرای پروژه روی لپ‌تاپ

بعد از دانلود، در همان Git Bash:

```bash
cd /d/saite

# نصب pnpm (فقط بار اول — اگر ندارید)
npm install -g pnpm

# نصب وابستگی‌ها (چند دقیقه طول می‌کشد)
pnpm install

# اجرای سرور توسعه
pnpm dev
```

سپس در مرورگر باز کنید: **http://localhost:3000**

| آدرس | چه چیزی ببینید |
