## 🔴 حکم کلیدی (قبل از هر چیز این را بخوانید)

پوستهٔ فعلی برای **یک کسب‌وکار دیگر** ساخته شده است.

| | پوستهٔ فعلی | چیزی که شما می‌خواهید |
|---|---|---|
| **حوزه** | گجت مصرفی (گوشی، هدفون، ساعت هوشمند) | تجهیزات اداری (پرینتر، کپی، قطعات) |
| **مخاطب** | کاربر جوان، خرید احساسی | مدیر اداری / کارشناس خرید، خرید منطقی و مقایسه‌ای |
| **تم رنگی** | مشکی `#0a0a0c` + بنفش نئون `263°` | سفید/خاکستری + سرمه‌ای + نارنجی |
| **لحن بصری** | Cyber/AI، ذرات شناور، لیزر، شیشه‌ای | شرکتی، مینیمال، تمیز، قابل اعتماد |
| **چگالی اطلاعات** | کم (کارت ۳۸۴px با ۳ داده) | زیاد (مشخصات فنی، سازگاری، موجودی) |
| **منطق خرید** | «افزودن به سبد» | سبد + **استعلام قیمت** + مشاوره + مقایسه |

این یک اختلاف «تنظیم رنگ» نیست؛ یک **تضاد در زبان طراحی** است. تم Cyber/AI با بنفش نئون به مشتری می‌گوید «اینجا گجت گیمینگ می‌فروشیم»، در حالی که پیام موردنیاز شما این است: «ما ۱۵ سال است دستگاه کپی Canon شما را سرویس می‌کنیم.»

**۶۴ نقطه** در کد، کلاس‌های تیرهٔ hardcode شده دارند (`bg-white/5`، `text-white`، `bg-black/30`) و **هیچ متغیر `dark:`** تعریف نشده — یعنی تم فعلی **قابل سوییچ نیست** و باید توکن‌ها از پایه بازنویسی شوند.

### ۲.۱. ✅ آنچه در پرامپت شما درست است

**پالت سفید/خاکستری + سرمه‌ای + نارنجی کاملاً درست انتخاب شده.** این دقیقاً زبان بصری صنعت است (Canon، Ricoh، Konica Minolta همگی در همین طیف‌اند). سرمه‌ای = ثبات و تخصص؛ نارنجی = فوریت کنترل‌شده روی CTA. توصیه‌ام فقط این است که نارنجی را **کمیاب** نگه دارید:

```css
:root {
  /* پایه — ۹۰٪ صفحه */
  --background: 0 0% 100%;          /* سفید خالص */
  --surface:    210 20% 98%;        /* خاکستری بسیار روشن برای کارت‌ها */
  --border:     214 20% 90%;

  /* برند — سرمه‌ای: هدر، عناوین، لینک‌ها */
  --primary:    215 60% 23%;        /* #17324f */
  --primary-hover: 215 60% 18%;

  /* تاکید — نارنجی: فقط دکمهٔ خرید و بج تخفیف. حداکثر ۲ بار در هر صفحه */
  --accent:     22 90% 52%;         /* #f56a16 */

  /* وضعیت موجودی — واژگان بصری اختصاصی این صنعت */
  --in-stock:     150 60% 36%;      /* سبز: موجود */
  --low-stock:    38 92% 50%;       /* کهربایی: موجودی محدود */
  --out-of-stock: 0 0% 60%;         /* خاکستری: ناموجود */
  --on-request:   215 60% 23%;      /* سرمه‌ای: تماس بگیرید */
}
```

> ⚠️ **تلهٔ رایج:** اگر نارنجی را روی هر دکمه‌ای بگذارید، دیگر «تاکید» نیست. قانون: در هر صفحه فقط **یک** کنش نارنجی باشد.

### ۲.۲. ⚠️ جایی که با پرامپت شما موافق نیستم

پرامپت می‌گوید «**مینیمال**». برای این دامنه، مینیمالیسم بصری درست است اما **مینیمالیسم اطلاعاتی غلط است**.

خریدار پرینتر می‌خواهد بداند: سرعت چاپ چند برگ در دقیقه؟ دوروی خودکار دارد؟ شبکه/وای‌فای؟ کارتریج چند صفحه می‌زند؟ **کارت محصول باید متراکم باشد، نه خلوت.**

کارت فعلی ۳۸۴ پیکسل ارتفاع دارد و فقط ۳ داده نشان می‌دهد. پیشنهاد من:

```
┌──────────────────────────────────┐
│  [ تصویر روی پس‌زمینهٔ سفید ]     │   ← تصویر کوچک‌تر (۱۶۰px)
│                        ● موجود   │   ← وضعیت موجودی، گوشهٔ بالا
├──────────────────────────────────┤
│  CANON                           │   ← برند (لاتین، خاکستری)
│  i-SENSYS LBP-2900               │   ← مدل، پررنگ
│  پرینتر لیزری تک‌رنگ              │
│  ─────────────────────────────   │
│  ⚡ ۱۲ ppm   📄 A4   🔌 USB      │   ← ۳ مشخصهٔ کلیدی
│  ─────────────────────────────   │
│  ۴,۸۵۰,۰۰۰ تومان                 │
```

این کارت **کوتاه‌تر** ولی **پرمحتواتر** است. کاربر می‌تواند ۴ محصول را بدون کلیک مقایسه کند.

```tsx
// الگوی پیشنهادی: URL منبع حقیقت است، نه useState
const searchParams = useSearchParams()
const router = useRouter()

const setFilter = (key: string, value: string | null) => {
  const params = new URLSearchParams(searchParams.toString())
  value ? params.set(key, value) : params.delete(key)
  params.delete('page')                       // بازگشت به صفحهٔ ۱
  router.push(`/products?${params}`, { scroll: false })
}
// /products?brand=canon&type=laser&sort=price_asc&page=2
```
