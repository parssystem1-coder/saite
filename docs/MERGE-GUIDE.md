# 🔀 راهنمای مرج برنچ کاری به main

> **برنچ:** `arena/019fc7c0-saite` → `main`
> **تعداد کامیت:** ۱۶
> **وضعیت:** آزمایش‌شده و تأییدشده — بدون تعارض

---

## ⚠️ نکتهٔ مهم پیش از شروع

تاریخچهٔ `main` در مخزن شما **squash شده** است: فقط یک کامیت دارد
(`95b68ac — Update ci.yml`) و هیچ جد مشترکی با برنچ کاری ندارد.

به همین دلیل مرج معمولی کار نمی‌کند:

```
fatal: refusing to merge unrelated histories
```

و اگر با `--allow-unrelated-histories` اجرا کنید، Git نمی‌داند کدام
نسخه جدیدتر است و **بیش از ۲۰ فایل تعارض** می‌سازد — در حالی که
واقعاً تعارضی وجود ندارد؛ فقط تاریخچه گم شده است.

راهنمای زیر این را حل می‌کند.

## ✅ روش پیشنهادی — پنج دستور

در **Git Bash** روی `D:\saite`:

```bash
cd /d/saite

# ۱. گرفتن آخرین وضعیت از سرور
git fetch origin

# ۲. رفتن روی main و هم‌ترازی کامل با سرور
git checkout main
git reset --hard origin/main

# ۳. شروع مرج (تعارض نشان می‌دهد — طبیعی است، نگران نباشید)
git merge --no-commit --no-ff --allow-unrelated-histories origin/arena/019fc7c0-saite

# ۴. گرفتن دقیق درخت برنچ کاری — تعارض‌ها یک‌جا حل می‌شوند
git read-tree -u --reset origin/arena/019fc7c0-saite

# ۵. ثبت کامیت مرج
git add -A
git commit -m "Merge branch 'arena/019fc7c0-saite' — فازهای A تا E + رفع باگ‌ها"
```

### دستور ۴ دقیقاً چه می‌کند؟

`read-tree -u --reset` می‌گوید: «محتوای نهایی باید **دقیقاً** برابر
برنچ کاری باشد.» این یعنی:

- فایل‌های جدید اضافه می‌شوند
- فایل‌های تغییریافته به‌روز می‌شوند
- **۱۰ فایل حذف‌شده واقعاً پاک می‌شوند** (مثل `pnpm-lock.yaml`
  و فایل‌های مرده) — کاری که `git checkout -- .` انجام نمی‌دهد

`MERGE_HEAD` هم دست‌نخورده می‌ماند، پس کامیت نهایی یک **مرج واقعی
با دو والد** است، نه یک کامیت معمولی.

## 🔍 تأیید پیش از push

```bash

# باید خالی باشد (یعنی درخت دقیقاً برابر برنچ)
```

## 🧹 پاک‌سازی پس از مرج

```bash

# حذف نسخهٔ محلی
git branch -D arena/019fc7c0-saite

# پاک‌کردن ارجاع‌های مرده
git remote prune origin
```

> اگر می‌خواهید برنچ برای مرجع بماند، این بخش را رد کنید.

## 🆘 اگر چیزی اشتباه شد

**پیش از push** — همه‌چیز محلی است و قابل برگشت:

```bash
git merge --abort              # اگر وسط مرج هستید
git reset --hard origin/main   # بازگشت کامل به وضعیت سرور
```

**پس از push** — برنچ کاری دست‌نخورده روی سرور است:

```bash
git reset --hard origin/arena/019fc7c0-saite
```

هیچ کاری از دست نمی‌رود.
