# سیاست پیشنهادی داده مشتری

- داده‌های لازم برای سفارش و مالی تا پایان الزام قانونی نگهداری شوند.
- داده‌های بازاریابی با رضایت و قابلیت لغو نگهداری شوند.
- آدرس‌های بدون سفارش فعال پس از مدت سیاست‌گذاری‌شده archive یا حذف شوند.
- soft delete برای مشتری نباید سفارش‌ها و فاکتورهای تاریخی را حذف کند.
- export و مشاهده داده حساس در audit ثبت شود.
