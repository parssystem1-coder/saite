# چک‌لیست تحویل به Arena

- [ ] فایل‌های phaseها با مسیر واقعی merge شدند، نه فقط کپی HTML.
- [ ] `npm run type-check` سبز است.
- [ ] `npm run lint` سبز است.
- [ ] `npm test` سبز است.
- [ ] `npm run build` سبز است.
- [ ] customer filters همه، VIP، تکراری، سازمانی و پیگیری واقعاً query/فیلتر دارند.
- [ ] shipping methods از settings به checkout می‌رسند.
- [ ] prepaid، COD، free و flat rate در UI و snapshot از هم جدا هستند.
- [ ] order totals فقط از server authority می‌آیند.
- [ ] inventory reservation transaction و idempotent است.
- [ ] packageها tracking و label مستقل دارند.
- [ ] return transition و refund audit شده‌اند.
- [ ] آدرس سفارش snapshot است و label از snapshot تولید می‌شود.
- [ ] اطلاعات مشتری در URL/log عمومی نرفته است.
- [ ] مسیرهای admin با `getAdminSession()` و permission محافظت شده‌اند.
- [ ] E2E مسیرهای بحرانی نوشته شده‌اند.
