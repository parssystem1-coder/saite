# استاندارد لیبل پستی

## قالب

- قالب پیشنهادی: A6، عمودی، 105×148 میلی‌متر
- حاشیه امن: حداقل ۵ میلی‌متر
- متن اصلی: حداقل ۱۰pt، نام گیرنده ۱۴ تا ۱۶pt
- چاپ: PDF یا PNG با 300 DPI، بدون scale-to-fit
- دو نسخه برای هر بسته: یکی روی بسته، یکی داخل پرونده سفارش

## داده‌های الزامی

فرستنده، گیرنده، تلفن، آدرس کامل، استان، شهر، کدپستی ۱۰ رقمی، شماره سفارش، شماره بسته از کل بسته‌ها، شرکت حمل، سرویس، وزن، ارزش اظهارشده و کد رهگیری.

## بارکد

برای پست واقعی، نوع بارکد را قرارداد شرکت حمل تعیین می‌کند. سیستم باید `barcodeValue` را از کد رهگیری بگیرد و رندر barcode را در سرور انجام دهد. پیشنهاد پیش‌فرض: Code 128 برای کدهای رهگیری عمومی. اگر شرکت حمل قرارداد QR یا GS1 دارد، renderer قابل تعویض باشد. بارکد را به‌صورت تصویر raster بی‌کیفیت تولید نکنید، SVG/PDF برداری استفاده کنید.

## چندبسته‌ای

هر بسته label مستقل دارد: `1 of 2`, `2 of 2`. اقلام و ارزش اظهارشده هر بسته جدا ثبت می‌شود. کل سفارش فقط بعد از چاپ موفق همه لیبل‌ها وارد `ready_to_ship` شود.

## کنترل چاپ

قبل از چاپ: کدپستی، شماره تماس، وزن، ارزش، شرکت حمل و شناسه بسته اجباری. چاپ مجدد باید `reprintCount`, `reprintedAt`, `reprintedBy` و دلیل داشته باشد و روی لیبل watermark «نسخه مجدد» بزند.
