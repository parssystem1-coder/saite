# چک‌لیست کامل بودن بخش سفارش‌ها

پوشش این نسخه: فهرست و فیلتر، وضعیت‌های عملیات، جزئیات گیرنده، تماس و آدرس، کدپستی، اقلام و SKU، چندبسته‌ای، نوع بسته، ابعاد، وزن، ارزش اظهارشده، بیمه، شکستنی، فاکتور، شرکت حمل، سرویس، هزینه، کد رهگیری، پیش‌نمایش لیبل A6، بارکد قابل تعویض، چاپ مجدد، مرجوعی، بازپرداخت، audit trail و کنترل دسترسی.

موارد اتصال به backend که باید پیاده شود: endpointهای سفارش و بسته، renderer واقعی PDF/SVG، integration شرکت حمل، اعتبارسنجی کدپستی، upload امن مدارک مرجوعی، notification مشتری، چاپگر واقعی، RBAC جزئی برای انبار/مالی و تست E2E.
