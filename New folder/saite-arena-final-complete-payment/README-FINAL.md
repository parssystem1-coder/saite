# Saite final Arena bundle

این بسته کامل‌ترین خروجی اصلاحات گفتگو است: امنیت، login، cart، checkout، سفارش، fulfillment، split shipment، returns، customers CRM، shipping settings و اکنون domain foundation.

از `00-ARENA-INSTRUCTIONS/MASTER-PLAN.md` شروع کن. ترتیب P0 تا P5 عمداً بر اساس dependency و ریسک است. از UI شروع نکن؛ اول authority، transaction، idempotency و مدل داده را بساز.

این بسته ۱۰۰٪ backend production نیست و وانمود نمی‌کند هست. migration، API واقعی، gateway، carrier integration و E2E باید در فازهای مشخص‌شده توسط Arena تکمیل شوند.
